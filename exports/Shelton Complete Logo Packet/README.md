# Shelton Complete Logo Packet

This packet expands the selected Shelton Linen & Uniform Services review identity into a flexible layout system.

## Selected construction

- Canonical Shelton circled-S copied unchanged from `shelton-mark.svg`
- Sharp Grotesk Medium 25 company name, tracking `-26`, converted to outlines
- Capital `I` option 02: native Sharp stem, with the advance tightened symmetrically by `140` font units
- Ampersand option 04: Inter Medium, enlarged approximately 8% from the reviewed option
- Descriptor system: Commercial Laundry / San Diego in the approved muted gold treatment
- Descriptor lettering enlarged 15% from the initial packet for stronger legibility
- Palette: Deep Navy `#081321`, Warm Cream `#FAF6EE`, Muted Gold `#B8965A`

## Layouts

1. **Primary Horizontal** — Vehicles, signage, website headers.
2. **Signature Horizontal** — Wide print, storefronts, presentations.
3. **Panoramic All In One** — The complete identity on one uninterrupted line.
4. **Stacked Centered** — Posters, square layouts, apparel backs.
5. **Compact Vertical** — Narrow panels, garment fronts, banners.
6. **Wordmark Only** — Minimal headers and supporting applications.
7. **Editorial Split** — Statement signage and premium collateral.

Each layout includes four modes in both transparent outlined SVG and high-resolution transparent PNG:

- `light`: navy name with gold accents for cream or light backgrounds
- `dark`: cream name with gold accents for navy or dark backgrounds
- `one-color-navy`: fully navy production artwork
- `one-color-cream`: fully cream production artwork

## Quick use

- Start with **Primary Horizontal** for vehicles, signage, and the website.
- Use **Panoramic All In One** when the entire identity must read in one line.
- Use **Signature Horizontal** for a cleaner one-line company name with the descriptor below.
- Use **Stacked Centered** or **Compact Vertical** for narrow and square spaces.
- Use the one-color files for embroidery, vinyl cutting, screen printing, and restricted production.

Open `Shelton-Logo-Gallery.html` for the easiest local review and download experience.

Use the files in `logos/` as the vector masters. Use `png/` for office documents, email, social posts, and software that does not accept SVG.

## Production note

All visible lettering in the logo SVGs is outlined; vendors do not need the fonts to open the artwork. The supplied Sharp Grotesk font is a personal-use trial. License Sharp Grotesk before commercial production, printing, uniforms, vehicle work, signage, or public deployment.
