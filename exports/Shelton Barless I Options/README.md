# Shelton Barless I Options

Four review treatments replacing every capital `I` in the vehicle/signage logo:

1. Narrow Flat - a restrained, narrow vertical stem
2. Native Sharp Stem - uses the exact width of Sharp Grotesk's lowercase `l` stem, extended to cap height
3. Wide Flat - a heavier vertical stem for distance legibility
4. Rounded Stem - native width with subtly rounded terminals

Each replacement reduces the original capital `I` advance by `140` font units, evenly removing space from both sides of the narrower stem. The broader Sharp Grotesk tracking remains `-26`. The comparison uses Cormorant Medium ampersand option 01 and the expanded descriptor treatment with tracking `+185`.

The circled-S is copied unchanged from the canonical brand source. All visible lettering is converted to vector outlines.

Barless capital `I` forms can resemble lowercase `l` at small sizes, so the selected option should be checked at the intended vehicle, signage, and digital sizes.

The supplied Sharp Grotesk trial is personal-use only. These are review concepts, not production-cleared assets.
