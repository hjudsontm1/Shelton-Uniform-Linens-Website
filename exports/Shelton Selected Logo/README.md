# Shelton Selected Logo Concept

This package combines the selected review treatments:

- Ampersand 04: Inter Medium, enlarged approximately 8% from the reviewed option
- Capital I 02: Native Sharp Stem, with the approved tightened spacing treatment
- Descriptor: expanded tracking +185, spanning most of the divider width

The circled-S is copied unchanged from the canonical Shelton brand source. All visible lettering is converted to vector outlines.

`light` uses navy lettering for light backgrounds. `dark` uses cream lettering for navy or dark backgrounds. Both SVGs have transparent backgrounds.

The supplied Sharp Grotesk trial is personal-use only. This is a selected review concept, not a production-cleared asset. License the typeface before commercial production.
