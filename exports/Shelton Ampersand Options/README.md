# Shelton Ampersand Options

Four review treatments for the Sharp Grotesk vehicle/signage lockup:

1. Cormorant Medium - current balanced serif treatment
2. Cormorant Light Large - more expressive and editorial
3. Cormorant Semibold Compact - smaller and sturdier
4. Inter Medium - clean sans-serif treatment

The commercial descriptor now uses tracking `+185`. `COMMERCIAL LAUNDRY` is left-aligned and `SAN DIEGO` is right-aligned to the wordmark/divider width, so the descriptor occupies most of the available span.

The circled-S is copied unchanged from the canonical brand source. Sharp Grotesk wordmark tracking remains `-26`. All visible lettering is converted to vector outlines.

The supplied Sharp Grotesk trial is personal-use only. These are review concepts, not production-cleared assets.
