# Shelton Cleaners identity assets

These files are the approved historic **Shelton Cleaners** identity for dry-cleaning applications. They are intentionally separated from the Shelton Linen & Uniform Services commercial identity in `../brand/`.

## Approved use

- Use `shelton-cleaners-lockup-dark.png` on white and other light surfaces.
- Use `shelton-cleaners-lockup-light.png` on dark surfaces.
- Use the standalone `shelton-cleaners-mark-*` only when the full name appears elsewhere in the same application.
- Do not redraw, retype, distort, recolor, regenerate, or substitute the circled-S or the Shelton Cleaners wordmark.
- Supporting copy may use Inter Medium from `../fonts/` and the shared palette: Deep Navy `#081321`, Warm Cream `#FAF6EE`, and Muted Gold `#B8965A`.
- Keep these assets out of Shelton Linen & Uniform Services commercial applications unless a layout is explicitly intended to represent Shelton Cleaners.

Before vendor production, replace these raster reference files with original vector artwork if it becomes available.
